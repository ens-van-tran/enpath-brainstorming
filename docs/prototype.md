# Prototype Review

## Run locally

From the repository root:

```bash
python3 -m http.server 8766 \
  --directory _bmad-output/planning-artifacts/ux-designs/ux-enpath-repo-2026-08-12/mockups
```

Open `http://localhost:8766/login.html` and choose a Product Role.

## Suggested walkthrough

### HR

1. Open **Teams** and create a Team such as `PDO`.
2. Enable reusable Organization Roles and assign one Primary Manager.
3. Inspect Members, Competency Library, Framework Templates, and Team Frameworks.
4. Open **Team Career Paths** and switch between Team-specific paths.
5. Open **Capability Overview** and compare achieved capability with development coverage.

### Manager

1. Inspect the assigned Team Framework and Learning Resources.
2. Create an Assessment and assign its Self-Assessment.
3. After Employee submission, issue separate Manager Ratings.
4. Review an Employee-requested Development Plan snapshot.
5. Open a multi-Competency Reassessment and decide each item independently.

### Employee

1. Inspect Official Rating, expected rating, gap, and `Unknown` states.
2. Browse the visual Team Career Path tree and select a reachable Target Position.
3. Complete an assigned Self-Assessment.
4. Maintain Development Actions and reusable Evidence.
5. Request advisory Plan review or submit one multi-Competency Reassessment Request.

### Contextual Reviewer

1. Open the scoped invitation.
2. Inspect only shared Criteria, question, and Evidence.
3. Submit qualitative context without selecting a Rating Level.

## Reset

Use **Reset demo data** in any workspace to restore the shared seed state.
